# Catch the Box 🎮

A simple and fun browser-based game where you catch a moving box to score points!

## About

Catch the Box is a reaction-based game built with vanilla HTML, CSS, and JavaScript. A box bounces around inside a container, and your goal is to click on it before it moves away. Each successful catch increases your score!

## How to Play

1. Open `index.html` in your web browser
2. Click on the moving box to catch it
3. Each catch adds to your score
4. Try to beat your high score!

## Features

- Smooth box movement with physics-based bouncing
- Real-time score tracking
- Simple, clean interface
- Responsive design
- No dependencies required

## Languages Used

- HTML5
- CSS3
- JavaScript
